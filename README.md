# BydNavi

Короткая https-страница: из обычной ссылки делает переход в приложение **Яндекс Навигатор**. Так маршрутом можно делиться в Telegram — мессенджер делает кликабельными только https-ссылки, а `yandexnavi://` из чата не открывается.

## Пример

https://us-kavalchuk.github.io/BydNavi/?lat=53.86&lon=27.45&name=Test

Страница сразу открывает:

```
yandexnavi://build_route_on_map?lat_to=53.86&lon_to=27.45
```

На Android автопереход и главная кнопка используют intent с пакетом `ru.yandex.yandexnavi`. Это браузерный аналог `ACTION_VIEW` + `setPackage`: Chrome и Telegram на телефоне отдают маршрут Навигатору, а не Яндекс Картам.

```
intent://build_route_on_map?lat_to=53.86&lon_to=27.45#Intent;scheme=yandexnavi;package=ru.yandex.yandexnavi;end
```

На головном устройстве (ГУ BYD) встроенный браузер Telegram часто блокирует и `intent://`, и `yandexnavi://`. Поэтому на Android страница показывает несколько настоящих ссылок-кнопок:

- Навигатор через `intent://` с пакетом
- Навигатор через прямую схему `yandexnavi://`
- Intent с `S.browser_fallback_url` (если приложение не открылось — маршрут в Картах в браузере)
- Приложение Яндекс Карты: `yandexmaps://maps.yandex.ru/?rtext=...&rtt=auto`
- Маршрут в Яндекс Картах по https
- Кнопка «Скопировать координаты»

Если ничего не открывается: в Telegram нажмите ⋮ / меню → **Открыть в браузере**, затем снова жёлтую кнопку.

## Параметры

- `lat`, `lon` — широта и долгота назначения, оба обязательны.
- `name` — подпись места на странице.
- `lat_from`, `lon_from` — точка старта. Нужны оба. Без них маршрут начинается от текущего места.

Старт и финиш:

https://us-kavalchuk.github.io/BydNavi/?lat=53.86&lon=27.45&lat_from=53.90&lon_from=27.56&name=Test

Без `lat` и `lon` страница показывает краткую справку и не пытается ничего открыть.

Яндекс для Навигатора 2.40+ просит подпись ссылки ключом доступа (`client` и `signature`). Ключа в этом репозитории нет, поэтому ссылка собирается без подписи — так описан маршрут в документации. Новые версии приложения могут ограничить неподписанный вызов.
